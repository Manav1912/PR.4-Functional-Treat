# Functional Treat 🧩

The **Data Analyzer and Transformer Program** is a Python-based
menu-driven application that allows users to enter and manage 2D data.
It provides options to display data summaries, calculate factorials,
filter values using a threshold, and sort data in ascending or
descending order.

The program also displays dataset statistics such as the minimum,
maximum, sum, and average values. It demonstrates the use of Python
lists, loops, functions, and basic data-processing operations.
